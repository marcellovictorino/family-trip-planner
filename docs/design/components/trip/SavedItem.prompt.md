One-line: the one-line saved/visited row — a place card stripped to name, area and the ♥ / ✓ toggles.

```jsx
<SavedItem name="Tivoli Gardens" meta="Indre By" favourite onVisited={...} />
```

Use inside a `<ul>` with 0.4rem gaps. A place that has vanished from a regenerated dataset still appears, named "<id> (no longer in the guide)".
